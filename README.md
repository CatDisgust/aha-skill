# Aha

**简体中文** | [English](README.en.md)

**让理解自然发生。**

Aha 是一个帮你把卡住的地方讲明白的 skill，可以在 Codex 和 Claude 中使用。读材料、写代码或学概念时，遇到某个概念、某一步推导、某段代码看不懂，把它带进对话，Aha 会从你已经懂的地方出发，一步步把它接上。

> v0.2.0 · 公开试用版，欢迎体验与反馈。

## 它解决什么问题

很多解释本身是对的，但你就是跟不上。原因通常是解释跳过了你还没有的东西：

- **起点**：没从你已经懂的地方讲起，或者建立在你的一个错误理解之上。
- **步骤**：讲的人觉得显然的一步没讲，例子从输入直接跳到了输出。
- **含义**：一个术语或符号代替了本该有的解释。

Aha 只做一件事：在你卡住的那一个点上，把这几样被跳过的东西补上，然后把节奏交还给你。它不接管整场学习，不安排课程，也不出整套练习。

## 什么时候会用到

- 问某个术语、段落、符号或代码是什么意思。
- 问为什么、怎么运作，或者推导中的某一步为什么成立。
- 问两个概念的关系或区别。
- 说某个解释没懂、太抽象，不管这个解释来自 Aha、课本、老师还是别的 AI。
- 说出了一个错误的理解，比如“竞争条件是不是因为每个线程有自己的副本？”
- 做任务时因为某个没懂的地方卡住，比如一条看不懂的报错。Aha 会先简短讲清原因，再继续完成任务。

你不需要说出“Aha”，也不需要先说清楚自己具体卡在哪里。

以下情况不会用到 Aha：纯执行的任务（写代码、改格式）、快速查询（某个函数的参数顺序）、询问看法或做决定（“该选哪个数据库”），以及出题、做闪卡、制定学习计划这类管理整场学习的请求。

## 它会怎么讲

- **从你说的地方接上**：你说了已经懂什么，就从那里讲起，不重讲你已经掌握的部分。
- **术语第一次出现时附上释义**：你没用过的词，第一次出现时就说清它是什么意思。
- **用一个例子走完中间状态**：不只给输入和结果，还展示中间每一步发生了什么。
- **点明常见误解**：如果有一个很多人都会有的错误理解，会直接指出来。
- **以结论收尾**：讲到最后，用一两句话说清核心关系。
- **可能留一道小题**：讲完一个核心机制后，可能在最后一行留一道换了一个条件的小题，让你用一次刚学到的东西。可以不答，直接继续你的事。

你可以随时直接提要求：

> “直接告诉我答案。”
>
> “先别说结论，给我一点提示。”
>
> “还是太抽象了。”
>
> “好了，先这样。”

## 第一次使用

安装后，从一个真实的问题开始，例如：

```text
我知道线程之间共享内存，但不明白为什么会产生竞争条件。
```

也可以带上你正在读的材料：

```text
下面这段推导我能看懂前两步，但不知道第三步为什么成立。

[粘贴相关内容]
```

如果想明确指定用 Aha，在 Codex 里写 `$aha`，在 Claude Code 里写 `/aha`。

## 安装方法

Aha 只包含指令文件，不需要额外的 API 密钥或服务。对话使用你在 Codex 或 Claude 中选择的模型。

### Codex

方式一：把下面这段话发送给 Codex。

```text
请使用 $skill-installer 安装 Aha v0.2.0：
https://github.com/CatDisgust/aha-skill/tree/v0.2.0/skills/aha
```

方式二：下载 [aha-v0.2.0.zip](https://github.com/CatDisgust/aha-skill/releases/download/v0.2.0/aha-v0.2.0.zip)，解压得到 `aha` 文件夹，把整个文件夹放进用户级 skill 目录 `~/.agents/skills/`，确认指令文件位于 `~/.agents/skills/aha/SKILL.md`。

安装后，如果 Codex 没有识别到，重新打开 Codex 再试。目录说明见 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

### Claude Code

下载并解压 [aha-v0.2.0.zip](https://github.com/CatDisgust/aha-skill/releases/download/v0.2.0/aha-v0.2.0.zip)，把 `aha` 文件夹放进 `~/.claude/skills/`，确认指令文件位于 `~/.claude/skills/aha/SKILL.md`。目录说明见 [Claude Code 官方文档](https://code.claude.com/docs/en/skills)。

### claude.ai

下载 [aha-v0.2.0.zip](https://github.com/CatDisgust/aha-skill/releases/download/v0.2.0/aha-v0.2.0.zip)，不用解压，直接在 claude.ai 的设置中上传到 Skills。需要开启代码执行功能。具体步骤见 [Claude 帮助中心](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills)。

`~` 代表你的用户主目录。同一个平台只装一份，不要在多个 skill 目录里重复安装。

### 从 v0.1 升级

把原来的 `aha` 文件夹移到 skill 目录之外留作备份，再把新版 `aha` 放回同一位置。需要回退时，用备份恢复即可。

v0.2 改变了 Aha 的定位，升级前请留意：

- **只负责一次讲解**：v0.1 会管理整场辅导，包括开场、三个阶段、收尾复述和疲劳时暂停；v0.2 只负责把当前这个卡点讲清楚，学习节奏交给平台自带的学习模式或你自己。
- **新增“什么时候不用”**：明确排除了纯执行、快速查询、询问看法和管理会话这几类请求。
- **检验题改为固定规则**：每次讲解最多一道，放在最后一行，答案必须明确；你只要答案、在赶时间或上一道没回答时，就不出题。
- **篇幅减半**：指令文件从约 20KB 精简到约 10KB。

## 设计依据

Aha 的写法参考了认知负荷理论和自我决定理论：讲解要降低你理解解释本身所花的力气，同时把“用一次”这部分思考留给你，不让“读懂了”冒充“理解了”；你的明确要求，比如要答案、要提示、想停下，始终优先于默认的讲解方式。这些理论只作为设计依据写在这里，SKILL.md 里只保留由它们推出的具体做法。
