# Aha

**简体中文** | [English](README.en.md)

**让理解自然发生。**

Aha 是一个帮助你构建理解的 Codex skill。读材料、写代码或学习概念时，把卡住的地方带进对话，从你已有的理解出发，一起弄清关键关系、背后的机制，以及“为什么”。

> v0.1.0 · 公开试用版

## 什么时候使用

当你遇到这样的时刻：

- 定义记住了，却说不清它为什么这样工作。
- 推导看到了某一步，但不明白这一步为什么成立。
- 代码能够运行，但你还不理解背后的设计。
- 已经知道“这里没懂”，却说不清具体缺了哪一块。

把问题、相关材料，或你目前的想法交给 Aha 就可以开始。你不必先准确诊断自己的卡点。

首版面向计算机科学、人工智能、软件工程与系统相关概念。

## 第一次使用

安装后，从一个真实的问题开始，例如：

```text
用 $aha 帮我理解进程和线程。
我知道定义，但不明白共享内存为什么会带来竞争。
```

也可以带上你正在读的材料：

```text
用 $aha 帮我理解下面这段内容。
我能跟上前两步，但不知道第三步为什么成立。

[粘贴相关内容]
```

安装步骤见下方的[安装方法](#安装方法)。

## 它如何帮助你

Aha 会结合你的问题、已有理解和对话中的反馈，选择合适的帮助方式：

- **先搭框架**：看清一个概念要解决什么问题，以及它在整个系统中的位置。
- **解释机制**：把关键步骤和因果关系讲清楚，补上需要的基础。
- **借助例子和类比**：从熟悉的情境进入，再连接回真实概念。
- **用问题推进思考**：在你愿意继续推理时，帮助你发现联系、检查假设。

如果当前的解释或提问没有帮上忙，Aha 会根据你的反馈调整范围、节奏或帮助方式。你也可以直接提出偏好：

> “先直接讲完整流程，我想看看全貌。”
>
> “这个类比我没跟上，换一个更熟悉的例子。”
>
> “先别告诉我结论，给我一点提示。”
>
> “我有点累了，先停在这里。”

Aha 的目标是提供足够的支持，让你逐渐能自己说清其中的联系、解释它为什么成立，并继续原本的学习或工作。

## 安装方法

需要已能正常使用的 Codex，以及本地 skill 的安装权限。Aha 本身只包含指令和展示信息，无需额外 API 密钥或服务；对话使用你在 Codex 中选择的模型。

### 方式一：让 Codex 安装

把下面这段话发送给 Codex：

```text
请使用 $skill-installer 安装 Aha v0.1.0：
https://github.com/CatDisgust/aha-skill/tree/v0.1.0/skills/aha
```

### 方式二：下载 ZIP 手动安装

1. 下载 [aha-v0.1.0.zip](https://github.com/CatDisgust/aha-skill/releases/download/v0.1.0/aha-v0.1.0.zip)，解压得到 `aha` 文件夹。
2. 将整个 `aha` 文件夹放入用户级 skill 目录 `~/.agents/skills/`，没有该目录时先创建。
3. 确认指令文件位于 `~/.agents/skills/aha/SKILL.md`。

`~` 代表你的用户主目录。两种方式任选其一，无需重复安装。

安装完成后，在下一条消息中使用 `$aha` 开始对话。如果没有识别到，重新打开 Codex 后再试。

安装与目录说明参考 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。
